REPORTS FOLDER
==============

This folder stores generated observation report files.

Typical Contents:
- *.xlsx - NA and TT Excel report forms
- *.xml - Occult 4 export files

Notes:
- This folder is fixed at data/reports/ in the install layout
- Report templates are sourced from resources/templates_master/reports/
- Event cache files are stored in data/events/
- Generated sequences are stored in data/sequences/

Generated reports are saved with filenames based on:
- Event date and time
- Asteroid name and number
- Observer name
- Report type (NA or RASNZ)

Example: 20251107_778_Theobalda_UCAC4_361_199861_Smith_NA_Report.xlsx

Reports are generated from AOTA/Tangra analysis results and can be
submitted to regional coordinators for official inclusion in databases.

IMPORTANT: Report generation is experimental and not yet approved.
Always verify all data before submission.
