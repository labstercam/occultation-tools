# SharpCap Occultation Just Record Template
# Michael Camilleri

# Bare bones Sequence to Record at the event time with the required settings
# Intended for 'ad hoc' use when users want to record interactively
# Assumes the user has already set up the camera recording the way they need to#Does not do the GOTO, plate solve.
# Does not set format, bining, ROI etc. It justs records

SEQUENCE
    #Asteroid {object_name} at {event_time}
    #Star Mag: {star_mag};	Combined Mag: {comb_mag}; Mag Drop: {mag_drop}
    #Predict Time {event_time}; Error In Time: {time_error}
    #MaxDuration: %MaxDuration%; Probability: %Probability%
    
# Setup for the event
    TARGETNAME "{object_name}"

# Record
# Wait until the recording start time
# If you start late it will record anyway
    SHOW NOTIFICATION "Waiting for recording start at {start_time_local} " COLOUR Green DURATION 58
    WAIT UNTIL LOCALTIME "{start_time_local}"
    CAPTURE {recording_duration} SECONDS LIVE FRAMES
    SHOW NOTIFICATION "Recording Complete. Reseting camera and parking mount in safe position if required." COLOUR GREEN DURATION 30

END SEQUENCE
